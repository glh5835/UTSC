## 三 公共格式与模式隔离

文本采用 UTF-8；集合用数组，缺失标量用 `null`，空字符串标准化为缺失；`0` 仅表示可计算的零。对象 ID 为非空字符串，跨对象外键必须有效。时间戳用带时区的 ISO 8601，系统产生的构建、审核、发布时刻保存 UTC；日期单独用 `YYYY-MM-DD` 并保留精度。未知日期不能补今天。

文件哈希对原始字节计算 SHA-256。`content_hash` 对被审核的业务内容、来源内容哈希及相关词典/规则版本计算 SHA-256：UTF-8 JSON，键按名称排序，无额外空白，保留 Unicode 和显式 null，数组保持既定顺序；排除 content_hash 自身、审核状态和审核/发布操作时间。分类审核的业务内容还须包含对应岗位正文、标题及自动提议标签的哈希。任何输入内容或相关规则版本变化，旧批准都不能自动继承。

| 模式 | 数据与标识 | 发布及展示条件 |
| --- | --- | --- |
| HISTORICAL | 来源真实、使用范围明确的固定历史岗位；源批次、文件哈希及原采集时间可追溯 | 仅解释该快照样本；不说明今天仍招聘，不外推加拿大全部市场 |
| SYNTHETIC | 人工编写岗位、边界样例及测试资源，ID 使用 `SYN:` 前缀；时间标作 `FIXTURE` | 所有页面、导出和质量报告标明人工样例；不证明真实市场、课程或活动存在 |

两种模式分别具有 raw、manifest、派生快照和 release 命名空间；不混合统计，不自动回落到另一个模式。模式切换使旧筛选结果、比较、行动与导出失效；个人自述可以保留。禁止用隐藏样例补齐历史分组。

真实已核对资源可被显式引用到两套发布包，但各包固定自己的资源版本和来源；不能因此把 SYNTHETIC 岗位称为真实。人工资源使用 `origin_kind=TEST_FIXTURE`，不冒充官方。本项目设计的真实练习用 `PROJECT_DESIGNED`，与测试假资源不同。

以下是最小逻辑对象，不强制一对象一文件或一张表。未来可用 JSONL 与 SQLite；本阶段只写契约。公共记录均带 `contract_version`，公共持久对象带所属 `data_mode`；profile 和 action 为会话对象，引用当前模式与 release。

## 四 最小字段契约

### 4.1 manifest

| 字段 | 类型与约束 |
| --- | --- |
| `snapshot_id`, `data_mode`, `contract_version` | 唯一版本 ID；模式为上节两值；版本必须受支持 |
| `source_batches[]` | 每项含 `batch_id`、原提供方、`source_ref`、本地相对路径、字节数、完整 SHA-256、格式；路径不能逃逸数据根目录 |
| `usage` | 上节四种使用状态、范围证据、署名要求；HISTORICAL 发布至少须明确数据内部演示许可，随包分发另查许可 |
| `collected_start`, `collected_end`, `collection_timezone`, `time_basis` | 真实原采集区间及其依据；`SOURCE_COLLECTION / FIXTURE`；未知不从文件名或构建时间补造 |

| `policy` | 完整保存 100 字符正文阈值、35 天年龄、阻断问题集、地区映射及本文件默认规则；不能只有版本名无配置内容 |
| `counts`, `quality_ref` | 验证后才填写实际层级计数与质量报告引用；未导入为 null，成功验证后的空集才可为 0 |

缺源文件、哈希不符、模式冲突、必要版本不全或许可条件不满足，均阻断该历史快照发布。脏记录可隔离并计入质量报告，不要求删除它们才能发布其余合格样本。

### 4.6 profile 与 action（仅会话）

`profile`：`target_role`、`target_stage`、`market_area`、`skill_states`、可选 `courses_text`、`experience_text`、`profile_revision`。每个技能含 `experience_state=NOT_PROVIDED / STUDIED / PRACTICED` 与 `wants_practice=true / false / null`，允许“有经历且仍想练习”。未填保留 NOT_PROVIDED；自由文本不自动推断能力。

`action`：`action_id`、`resource_id` 或 `opportunity_id`、`target_skill_ids`、`reason`、`first_step`、`expected_output`、`conditions`、`eligibility_status`、`source_refs`、`data_mode`、`release_id`、`profile_revision`、`generated_at`、`stats_basis`。没有市场样本时 stats_basis 明确为 `GENERAL_EXPLORATION`，不生成市场差距；条件未知可建议“先核实资格”，不能写“现在可报名”。排序遵循需求规格第五节：用户想练习优先、已审核适用资源优先、固定 ID 打破并列、资源去重，最多三个，不凑数。

个人自由文本不入公共数据库、自动日志、审核记录或自动截图；只在当前会话保留，用户主动下载才写入下载文件。输入、模式、release 或资源时效状态变化使结果和待导出内容失效，重算后才能下载。清空、新会话、服务重启不恢复个人画像；不删除公共资源和审核。

## 五 去重、日期与正式样本

按以下顺序处理，始终保留 raw 和每个来源位置：

1. 验证文件结构、ID 和采集时间。缺 ID 的输入隔离，不能由标题造 ID。无效采集时刻进入待审，不能拿处理时间补。
2. 按提供方命名空间加 job ID 分组。同一有效采集时刻、关键内容相同则合并命中；不同则整组 `DUPLICATE_CONFLICT` 待审，不任意挑一条。关键内容包括标题、机构、国家省市、正文、发布日期及来源 URL。不同有效采集时刻取最新观察值，保存旧观察和查询历史；最新值不合格时不得偷偷退回旧值。跨提供方相似标题不自动模糊合并，另记疑似重复限制。
3. 用原采集时点判断岗位年龄。默认 `max_age_days=35`，按来源已声明时区的采集日期减发布日期，闭区间 `0 ≤ age_days ≤ 35`。精确时间已知且发布晚于采集时刻即为未来日期，即使同日也排除。仅日期则保留日期精度；缺发布日、无效日期、负年龄或超过 35 天均排除，不能伪装当前开放岗位。
4. 非加拿大排除；国家不明、地点映射不明、角色或阶段歧义、资深标题、初级标题与多年经验冲突等，进入阻断性待审。明确不在五方向或三阶段范围的记录排除；无法判断是否在范围内先待审。
5. 其余字段校验通过且无阻断问题才为正式岗位。正文缺失或短正文仅作为非阻断质量提示，正式岗位仍可计入总数，但不进入技能分母。

`disposition` 只能为 `FORMAL / PENDING / EXCLUDED`，多原因保留 reason_codes，另指定一个 primary_reason 供互斥计数。去重前的坏行、缺 ID 输入、重复或被更新观察独立统计。待审问题获批准解决且内容哈希仍匹配后才可转正式；“在审核队列中”本身既不表示全部排除，也不表示全部可用。

正文清理默认 `text-clean-1`：标准化换行、去 HTML 标签及不可读控制字符、HTML 实体解码、连续空白折为一个空格并去首尾空白，不删正文词语。`description_usable` 要求清理后至少 **100 个 Unicode 字符（含内部空格）**，且不是空模板、纯 URL 或乱码。100 包含边界；99 不足。可读性不能判断时标为待核对正文并移出技能分母，不自动补文本。清理规则变更须重算字符数与匹配位置。

## 六 统计口径

| 名称 | 定义 |
| --- | --- |
| 原始行数 I | 实际解析的原始记录行数；坏行另列，不能把文件大小换算为岗位数 |
| 候选数 C | 可识别 ID 去重后的候选组数，包括待审冲突组；缺 ID 输入另列，不混进 C |
| 正式数 F、待审数 Q、排除数 E | C 内互斥分区，`C = F + Q + E`；同岗位多原因不能重复加总 |
| 可分析正文数 D | 当前同模式、同 release、角色、地区、阶段下 F 中 description_usable 为真的岗位数 |
| 描述不足数 | 同一筛选范围 `F - D`，包括缺失、短、不可读正文，质量页可细分 |
| 技能计数 M(s) | D 中至少一次有效命中技能 s 的唯一岗位数，别名合并、重复提及一次 |
| 技能提及率 | D > 0 时 `M(s) / D`；D = 0 时为 null，显示不可用，不显示 0% |
| 比较百分点差 | 两侧 D 均大于 0 时 `100 × (M_left / D_left - M_right / D_right)`；否则 null |

总览同时显示 F、D、F−D。不能把未分析正文算成未提及；D>0 且没有命中时 M=0、率=0 合法。技能列表未包含的技能表示未分析，不能自动输出 0。比例存小数，展示百分比时默认一位小数，排序与差值用未四舍五入数。

筛选候选、待审、排除数仅在其相关元数据可定位时归入筛选组；缺标签或地点不能归组的记录单列“无法分组”，不伪装成过滤后消失。全量质量报告同时提供 C、F、Q、E 及输入坏行和重复去向。

All Canada 是本快照已映射加拿大分组的合计；单个 job 只有一个生效角色、阶段及地区，防止重复计数。比较必须同模式、release、地区、阶段，两个不同角色各用自己的 D。共同技能为两边 M 都大于零；单侧检出不叫职业独有技能。任一组 F 或 D 小于 20 均给探索性提示并显示实际 F、D；零样本单独说明，不推断全国需求或必需技能。

## 七 资源、活动与审核规则

课程目录存在、本学期开设、资源报名开放和用户符合资格是四件事。未知条件只能建议核实，已知不符合则不提供立即报名动作。审核过的资源与技能映射可用于学习探索；条件未知不阻止阅读介绍或本地练习。缺来源、待核对或已失效映射不进入自动行动。

活动以 `America/Toronto` 处理当地日期，并保留来源明确的其他时区；不硬编码 UTC 偏移。来源未给时区时不得用 Toronto 默认值冒充事实，须标待确认。缺年份、日期无效或时区不明为 DATE_UNKNOWN；已取消为 CANCELLED；有确定截止或结束且已过期为 EXPIRED。只有日期时按该地日历日比较：今天晚于该日才确定过期；同日标“具体时刻待确认”，不编造 23:59 或显示立即报名。夏令时重复或不存在的本地时刻需核实时区偏移后才可用于即时动作。

`registration_status` 独立于活动时间：未来举办不代表报名开放。进入“现在报名”动作需来源、审核、资格、报名开放及尚未过截止同时成立；未知则转“先核实”。演示时间用当前实际时刻；历史岗位快照不会冻结活动时效，离线也要重算日期状态。

本版资源复查默认：普通课程/实践内容 90 个日历日、活动状态 7 个日历日，或来源明确的更早失效日，以较早者为准；从 verified_at 的资源当地日期计算，当前日期超过复查日标 NEEDS_RECHECK。这是本项目的保守默认，非学校承诺或上游既有规则。来源内容变更立即重新核对；到期说明可继续读，但不作已确认可参加行动。

资源制作目标仍为 15–25 条；最低演示门槛为 **10 条来源与条件经核对的独立课程或实践资源**，同资源多技能映射只计一条。纯导航入口、自编练习和测试假资源另计，不靠它们补足该门槛；此为本版明确的验收计数口径。每个展示行动路径的方向须有可用资源；有效活动允许为零。未逐条核实前不填已完成数量。

## 十三 MVP-04 资源目录实现补记

沿用本契约资源最小字段，新增来源摘要和证据绑定的工程字段，不改变岗位/词典/统计规则。`data/resources/utsc-resources-v1/` 是独立固定资源包，包含 resources、mappings、sources、opportunities、两份练习说明及虚构 CSV；manifest 保存成员 SHA-256/字节数、内容派生 catalog_id 和既有 synthetic-skills-1 词典哈希。目录与招聘模式独立：OFFICIAL 不表示已经取得 HISTORICAL 岗位，PROJECT_DESIGNED 不加入学校资源计数。

内容核对状态使用 AGENT_VERIFIED、PROJECT_AUTHORED、NEEDS_RECHECK，明确区别于 review 对象的正式 APPROVED；核对人写 AGENT，不冒充 HUMAN，不建立审核库或发布指针。15 门课程描述/条件已读取，6 个受阻入口不计入门槛，2 个练习独立标记；所有课程当期开设、开放名额与个人资格仍 UNKNOWN。普通资源当地核对后 90 日（或更早明确复查日）过期即 NEEDS_RECHECK，说明可继续读但不进入已核对技能筛选。

沿用 sql、python ID，仅 2 条官方直接关系和 2 条练习 PRACTICES 为已核对内容；CSCB20 的 SQL 关系仍待审。映射绑定资源内容哈希与来源摘要/练习哈希，变更而未重新核对则加载失败；未检出映射不等于课程没有价值，也不从先修里提到的语言推断课程会教授该语言。

目录提供技能、类型和学习等级筛选；等级是本项目浏览标签，不代替官方先修或岗位职业阶段。无岗位导入、缺 HISTORICAL 招聘文件时也能读目录，不回填任何招聘计数。原始 URL 和代理摘要本地保存，运行时不访问网络、没有自动采集器。

正式精选活动为零。日期逻辑使用实际当前时刻和来源时区（普通本地状态按 America/Toronto）；DATE 只比较日历日，同日标 TIME_UNCONFIRMED，不生成假的时间。DATETIME 必须有可解释偏移；缺年份/时区、无效日期和未消解夏令时为 DATE_UNKNOWN；确定过期、取消、未来与报名状态分别保留。活动复查按 7 个当地日，本阶段不生成任何报名或画像行动。合成活动卡只存在 tests/artifacts 的隔离测试包。


## 十四 MVP-05 会话与确定性探索补记

沿用 profile/action 字段与原技能 ID。profile 仅 st.session_state：目标角色、独立目标阶段、sql/python 的三种 experience_state 与独立 wants_practice、可选课程/经历、revision。地区沿用共享筛选；比较页带入一侧角色及共享阶段，不自动填技能。自由文本不做关键词/能力推断，也不复制进原因、行动或日志。

规则版本 session-exploration-1：明确想练习时优先这些技能，允许 PRACTICED 且 wants_practice=true；未选择时，从样本 M>0 且未自述 PRACTICED 的技能探索。没有快照或 D=0 时为 GENERAL_EXPLORATION，只从仍有效的已核对资源探索，不计算市场差距。无候选/无有效资源则给具体空状态。

技能按未舍入提及数降序和 skill_id 打破并列；每个技能内按探索等级适合度、独立本地练习优先于未知资格的课程、固定 resource_id 排序，合并相同 resource_id 的目标技能，最多三个。等级只作浏览偏好：未填/学过默认从 BEGINNER，再 INTERMEDIATE、ADVANCED；自述有实践且想练习优先 INTERMEDIATE，其余保持稳定顺序，绝不据此判定选课资格。已知 INELIGIBLE、CLOSED、CANCELLED、EXPIRED 资源排除；未核实/到期映射不使用。

MVP-04 的不可变包仍保留原 action_generation_enabled=false，表示该阶段没有行动生成；本次授权由独立 session-exploration-1 在内存中组合已核对内容，不修改原包、不将 AGENT 升格为 HUMAN/APPROVED。仅生成 OPTIONAL_LOCAL_EXERCISE 或 READ_AND_VERIFY。官方课程资格和开设仍 UNKNOWN，首步是读说明和核实先修/课表；不生成报名、学分、已掌握技能承诺。没有 release，release_id=null，改用实际分析 ID、catalog_id、模式与规则版本绑定当前内部结果。

结果签名包含完整当前画像（只在内存求哈希）、模式、地区、分析 ID、catalog_id、资源有效状态和映射内容。输入/来源/状态变化会标记 dirty 并隐藏旧行动，显式重生成后才显示；即使改回原值也不恢复旧行动。每次进入或点击 Refresh resource status 都按实际当前时间重新核对资源状态。没有自动联网更新。

跨页保留永久会话 profile；临时控件进入页面时从它恢复。清空重置 profile，递增控件 epoch，删除所有旧 pf_ 控件、行动/对照/待导出及结果/dirty 状态；旧 epoch 的延迟回调被丢弃并清理，不能回填。没有数据库、公共缓存、localStorage 或文件保存个人信息。测试只用独立合成自述，所有自动截图遮挡 textarea，不留整页 HTML 转储；日志和文本产物做测试哨兵泄漏检查。完整发布、审核库和下载仍待 MVP-06。


## 十五 MVP-06 本地审核、完整发布与导出补记

本次不改变契约版本、原始字段、去重、历史日期或 M/D 定义。新增工程实现 `local-release-1`：默认启动学生只读；`run_local.py --maintenance` 显式打开可信本机维护，绝非账号、认证或安全机制。维护区公共来源及理由可持久化，个人 profile 从不传给审核/发布函数。

公共 SQLite 记录按模式隔离的 draft、追加 review、current 指针与 publication history。draft 固定源分析/目录身份；审核保存保留 review_id、object_type/id、base_content_hash、old_value/new_value、reason、reviewer_id、review_method=LOCAL_MAINTENANCE、UTC reviewed_at、status、rule_version、supersedes_review_id。编辑字段有白名单：分类角色/阶段/分区；资源开设/开放/先修/条件；映射关系/证据说明；活动报名/日期/精度/时区。raw、原提议、原始核对时间、来源及全部历史不覆盖。自由文本理由须只填写公共审核依据，不能粘贴学生信息。

保存不改变 current。DRAFT 审核仅保存，使用该对象最新非 DRAFT 决定；APPROVED 应用修改；REJECTED / NEEDS_RECHECK 暂停正式分类或资源/映射/活动有效性。APPROVED 只是本地决定，不代替 HUMAN 一致率。资源/映射/活动原依据未经核对时，禁止仅点击 APPROVED 升级；需先取得新的已核对来源包。本次未新增官方内容核验。已有已核对条目的本地决定记 LOCAL_VERIFIED，沿用原核对时刻及 90/7 日复查时限，不延长有效期。资源内容改变使旧映射 NEEDS_RECHECK，除非在最新资源修改之后明确重新审核其关系并一起发布；旧内容哈希不同的有效审核阻断发布，须新审核替代。分类有效值与 extraction proposal 分开，正式统计与明细使用 effective 值，原规则提议可追溯；标签审核不能修复非加拿大、坏日期、冲突原始观察等阻断事实。

完整包包含 analysis.json（岗位、提及、质量、统计、规则及原始来源引用）、dictionary.json、catalog 下完整资源/映射/来源/活动/练习、reviews.json、validation.json 和外层 manifest。分析 ID / catalog_id / mapping_version / review_version 均从内容派生；release_id 从完整清单派生。manifest 字段沿用本契约 release 约定，额外记录 publisher_version、draft_revision、action_policy=session-exploration-1、scope=LOCAL_ONLY。包内源目录历史 NOT_PUBLISHED / action_generation_enabled=false 保留其原阶段含义，学生发布身份与行动规则以外层发布清单为准。

先写私有 `.building-*`，验证所有成员集合、SHA-256/字节数、模式、词典、证据绑定、审核、岗位唯一性、分类有效值、提及及统计/质量一致性，再原子换名为不可变完整目录。current 与带原因的发布历史在同一 SQLite 事务更新，事务失败全部回滚，原有效包与保存审核不变；失败临时目录或未激活完整包可保留作诊断，均不自动成为 current。回退只允许曾发布的同模式完整包，重新校验目标后一次更新指针并追加历史，不删除新审核或改写旧包。不支持多人协作账户/远程部署；本机并发写入通过事务和草稿 revision 冲突检查拒绝过期发布。

学生会话保存单个完整 bundle 对象，初次进入可加载 current，模式切换先清旧 bundle；已打开会话即使 current 改变，也保留全部旧成员并提示可用更新。只有 Reload published version 校验成功后才一次替换岗位、目录、映射、审核；失败保留旧完整内存版本，不混用新目录。统计和行动签名新增 release_id，资源/活动仍按当前时间计算有效性；Refresh resource status 只刷新已载入版本的时间状态，不偷偷载入维护草稿。无完整发布时显示缺版本，不读取散装目录或切换模式补样本。无岗位样本但有完整发布时仍可生成明确 GENERAL_EXPLORATION 的资源阅读/本地练习。

CSV 为 UTF-8 BOM，含 SKILL 与 JOB_SOURCE 行；每行重复模式、发布时刻、发布/分析/资源/映射/审核版本、原发布区间/精度、原采集区间和筛选，两侧独立 F/D，技能行保留 M、未舍入率和百分点差，岗位行保留实际来源及逐条发布精度/时区/采集时间。D=0 的率/差值为 N/A，缺值不补零。字符串去除前导空白/控制字符判定后以 =、+、-、@ 开头时加前置单引号；可信数值的负百分点差仍是数值；逗号、换行、引号由 CSV writer 处理。

Markdown 明确包含目标、自述状态/想练习及用户主动填写的课程/经历（文字围栏）、数据模式、全部版本、发布时刻、原发布/采集区间、M/D、探索性/通用探索说明、最多三个行动的原因/首步/产出/来源链接/条件。本地材料链接指向该已发布包中的绝对路径；复制到其他电脑后需一并提供本地包或自行调整路径，不保证外链离线可访问。内容仅在会话内存生成，主动下载文件可含个人自述；不写公共库、包或日志。下载前按当前输入/已载入版本重新计算；dirty 或签名不符不提供旧下载。清空删除所有关联个人结果；公共审核、包和指针仍保留。自动截图遮挡所有 textarea，测试下载使用独立 SYNTHETIC 自述并单列为主动导出证据。
