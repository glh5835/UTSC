## 二 环境、安装与离线边界

本机已验证 CPython 3.10.11、Streamlit 1.65.0、pandas 2.3.3、Plotly 6.9.0；完整49项版本固定在 requirements-lock.txt。包不含 Python、虚拟环境、浏览器登录资料或离线 wheel 仓库。**本机启动.bat 依赖原工作区已有环境**；换电脑或移除该环境后不能承诺双击即用。

在其他位置，先使用自己的独立 Python 3.10 创建包内环境，再双击标准 `启动 UTSC 职业导航.bat`：

```powershell
Set-Location '你的解压目录\UTSC-Career-Navigator-MVP07'
& '你的Python3.10完整路径\python.exe' -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements-lock.txt
& '.\.venv\Scripts\python.exe' -X utf8 run_local.py
```

首次安装可能需要包源网络；本轮没有安装新依赖，也未在另一台电脑执行安装。依赖就绪后的已发布概览、比较、画像、课程阅读、审核和导出只读本地资料。外部原始网页和校内服务不随包镜像，断网无法打开它们，仍可读取保存的来源、条件、练习和证据说明。没有招聘/模型 API 密钥需求。

## 三 页面与版本

侧栏默认 Toronto GTA；职业阶段 All / Internship or Co-op / New Graduate / Entry Level，概览角色五类。All Canada 只是已有分组的合计。比较页独立选择两个不同角色，读取同一个 release 和共享地区/阶段；各侧保留独立 F/D，技能按 M/D 计率。D=0 为 N/A，F 或 D<20 为探索性；单侧检出不叫职业独有技能。

My skills & next steps 可全部留空。未填表示未知，Studied 不表示掌握，自由文本不推断技能；明确想练习优先，最多三个去重行动。无岗位样本只给 GENERAL_EXPLORATION，无资源就给0条。未知资格只提供阅读条件和核实动作；独立练习标 PROJECT DESIGNED。表单跨页保留，修改后须重新 Generate next steps，旧摘要不可下载；Clear this profile and results 清空全部关联结果。

Courses & practice 按技能、类型、学习等级筛选；待审入口须主动勾选。课程存在、开设、开放及个人资格分开。真实机会为0是正常状态；过期、年份/日期/时区不明不作为立即报名。普通资源90个 Toronto 当地日、活动7日后需复查，时间状态按演示当前时刻变化，不能因历史岗位而冻结。

Compare directions 下载 CSV，含 SKILL/JOB_SOURCE 两类行、左右 M/D、率/百分点差及来源/原日期；My skills & next steps 下载 Markdown，含目标、自述、依据、条件、源网址和本地材料。CSV 公式前缀加单引号，缺失为 N/A；Markdown 个人上下文按文字围栏输出。下载文件由使用者主动保存，可能包含自述，应用不自动归档。Markdown 中本地材料指向当前包绝对路径；以后移动包须重新生成摘要，旧文件路径不会自动跟随。

## 四 本地维护与回退

停止学生服务后，执行同一启动器加 `--maintenance`。维护开关只是可信本机入口，**不是账号、认证或安全机制**；不开放远程访问。不要把学生自述写入公共审核理由。

首次维护时默认源目录指向当前包内固定分析与资源，先 Save draft sources。选择 classification/resource/mapping/opportunity，修改公共白名单字段，填本地维护标签和原因，Save review 追加持久记录；保存不改变学生版本。只有 Publish complete version 全包验证后才改变公共 current。待审依据不能靠点击 APPROVED 变已核实，LOCAL_VERIFIED 不等于 HUMAN；资源修改后旧映射要重新审核。

已打开的学生页显示可用更新，点击 **Reload published version** 一次切换岗位/目录/映射/审核。失败保留旧完整内存版本及公开保存的编辑；不得逐表拼接。Rollback complete version 选择曾发布的有效完整包并填原因，校验后回退指针，保留更新的审核历史，再由学生显式重载。

公共审核和完整包重启后保留，个人会话不自动恢复。移动已进行维护的目录后，如草稿仍指向旧绝对路径，重新填写当前包内分析/资源目录并保存草稿；已发布学生包不依赖草稿绝对路径。请只修改派生/公共维护数据，不改 raw 或原始附件。
