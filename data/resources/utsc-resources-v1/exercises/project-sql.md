# SQL · Query an invented activity table

PROJECT DESIGNED — not a UTSC course, assessment or activity.

Use a local SQL tool to count unique records by category, compare it with raw row counts, and explain a zero-result query.

Prerequisites: Basic SELECT/GROUP BY knowledge; a local SQL tool of your choice. This app does not install or execute it.

First step: Create a local table from sample.csv; count raw and distinct record_id values per category; retain a separate query for a category with no rows.

Expected output: A query file and a three-sentence explanation of denominators and empty results.

Self-check: Distinct record IDs total 3; total input rows 4. Never infer career demand from this invented table.

Input: sample.csv contains invented records only. No network or personal data is needed.
