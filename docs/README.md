`plans/` 中的历史文档保留当时的路径、日期、数量及执行边界。其
`E:\...` 链接属于原电脑上的来源定位，不是 GitHub 上的启动路径；
新 checkout 请使用本目录的相对链接与启动说明。原始聊天、财务材料、
历史包和完整本机测试目录未公开上传。

网站放入数据仓库或缺少本地 Git 的描述，仅代表该次审计时点。
网站后续在本仓库 `web/` 开发，数据侧保持独立。
